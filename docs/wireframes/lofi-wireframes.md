# Lo-Fi Wireframes – GVCN Digital (Bước 3)
Mục tiêu: tập trung luồng, bỏ qua màu. Ưu tiên cấu trúc rõ ràng, 1 cột mobile, bảng→card.

Screens đề xuất:
- W01: Dashboard (GVCN) – Công việc hôm nay, Evidence mới nhất
- W02: DS Học sinh (Lớp học) – Table + lọc
- W03: Hồ sơ HS – Card + lịch sử + minh chứng
- W04: Thông báo & Thiệp – List + Wizard 3 bước + Trạng thái
- W05: Khảo sát – Wizard + Danh sách + Kết quả
- W06: Nhiệm vụ – Theo trạng thái + Badge hạn
- W07: Theo dõi tiến độ – Table + Filter chips
- W08: Minh chứng (Evidence) – Card/Grid + Chi tiết (Evidence ID + QR + PDF)
- W09: Báo cáo – 1 màn + Preview + Xuất PDF
- W10: Trang chủ HS/PHHS – Gọn 3–4 khối
- W11: Public Link (Xác nhận) – Siêu đơn giản
- W12: Empty States – Hướng dẫn 1–2 câu
